## 📘 Overview

The Contact Book Manager is a simple Python program that demonstrates:

- Modular programming  
- Basic CRUD operations  
- Dictionary-based data storage  
- User interaction through a command-line menu  

Each feature is implemented in its own Python file for clean structure and readability.

---

## ⭐ Features

- **Create Contact** – Add a new contact (name, age, phone, email).  
- **View Contact** – View details of any saved contact.  
- **Update Contact** – Modify the info of an existing contact.  
- **Delete Contact** – Remove a specific contact.  
- **Search Contact** – Look up contacts by name.  
- **Count Contacts** – Show the total number of contacts saved.  
- **Exit Option** – Cleanly close the program.  

---

## 🛠 Technologies / Tools Used

- Python 3.x  
- Command Line Interface (CLI)  
- Modular file structure  
- Python dictionaries
